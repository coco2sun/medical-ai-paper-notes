📌 论文概览

两篇文章均采用 AI 从廉价 H&E 切片虚拟生成蛋白空间图谱，但定位、规模与应用方向截然不同

HEX

📗 Nature Medicine · 2026 | Stanford 等多中心
"H&E to protein expression: an AI model designed to computationally generate high-dimensional spatial proteomics profiles directly from standard histopathology slides"
  • 利用病理学基础模型（Foundation Model），从 H&E 预测 40 种蛋白的空间表达
  • 训练于 10 例 NSCLC 患者的 ~75.5 万 CODEX-H&E 配对 tiles
  • 验证于 7,317 名患者，涵盖 13 种癌症
  • 多模态融合框架 MICA 整合 H&E + 虚拟 CODEX 进行临床预测
  • 核心应用：早期肺癌预后 & 免疫治疗响应预测

GigaTIME

📙 Cell · 2025 | Providence Health + TCGA
"Multimodal AI generates virtual population for tumor microenvironment modeling — bridging cell morphology and states across 40 million cells"
  • 跨模态翻译器从 H&E 生成虚拟 mIF，训练于 4000 万细胞，21 种蛋白
  • 应用于 14,256 名真实世界患者（51 家医院，7 个美国州）
  • 生成 299,376 张虚拟 mIF 切片，覆盖 24 种癌症、306 种亚型
  • 发现 1,234 个统计显著关联（蛋白、生物标记、分期、生存）
  • 核心应用：人群规模 TIME 流行病学与生物标记发现

核心创新①：特征分布平滑（FDS）
解决蛋白表达分布长尾不均衡问题
⚠️
问题背景：蛋白表达值天然呈长尾分布——大多数 tile 中某蛋白低/不表达，只有少数区域（如免疫细胞浸润灶）高表达。传统回归模型在低样本区域（高表达端）容易欠拟合，产生系统性预测偏差。
FDS 数学原理（Feature Distribution Smoothing）
# 将训练样本按蛋白表达值分桶（bin）
输入: 特征 h_i，蛋白标签 y_i

# 每个 bin b 内计算均值和协方差
μ_b = mean({h_i : i ∈ bin_b})
C_b = cov({h_i : i ∈ bin_b})

# 用相邻 bin 的高斯核加权平均进行平滑
μ̄_b = Σm∈B g(y_b, y_m) · μ_m
C̄_b = Σm∈B g(y_b, y_m) · C_m

# 用校正后的统计量对特征做仿射变换
h'_i = sqrt(C̄_b) · sqrt(C_b)-1 · (h_i - μ_b) + μ̄_b

# 其中高斯核 g 控制平滑范围
g(y_b, y_m) ∝ exp(-|y_b - y_m|² / (2σ²))
💡
直觉理解：FDS 的核心思想是让"稀少的高表达样本"能从"大量低表达样本"借用特征统计信息，通过高斯核平滑，使不同蛋白表达水平区间的特征分布更连续均匀。训练时 FDS 作用于特征空间（而非标签空间），既减少高表达区域欠拟合，又不破坏判别性特征。
4
核心创新②：自适应损失函数（ALF）
对 CODEX 数据中噪声和离群点的鲁棒回归
⚠️
问题背景：CODEX 图像中存在非特异性背景荧光、抗体交叉反应、组织边缘伪影等噪声，导致少量 tile 的蛋白标签严重偏离真实值（离群点）。普通 MSE 损失对离群点敏感，会拉偏整个模型。
ALF 损失函数（Adaptive Loss Function）
# 广义鲁棒损失，形状参数 α 可自适应学习
ℒ(r, α, c) = ρ(r/c, α) + log Z(α)

# 核心 ρ 函数（统一多种损失形式）
ρ(r, α, c) = (|α-2|/α) · [ (r²/c² / (α-2) + 1)^(α/2) - 1 ]

# α 控制损失尾部行为（可学习参数）：
α → 2 : ≈ MSE（均方误差） ← 高斯噪声假设
α → 1 : ≈ L1 / Laplacian ← 中等鲁棒性
α → 0 : ≈ Cauchy 损失 ← 强离群点抑制

# 两个可学习参数（初始化均为 1）
α（形状）, c（尺度）→ 训练中自动优化
📈 ALF 与常见损失函数对比
  • MSE（α=2） 对离群点惩罚极大（二次增长），噪声标签严重影响训练
  • L1（α=1） 线性增长，适度鲁棒，但梯度在零点不连续
  • ALF 尾部"饱和"——超大残差的梯度自动趋零，等效自动剔除离群点；α 和 c 随数据自适应调整

MICA Co-Attention 数学形式
# 三路线性投影
Q = M_bag · P_q # Query: 蛋白特征提问
K = H_bag · P_k # Key: H&E 特征应答
V = H_bag · P_v # Value: H&E 内容提取

# Scaled Dot-Product Co-Attention
A_co = softmax(Q · KT / sqrt(d_k)) · V

# 直觉：蛋白通道（Query）去检索与之空间相关的 H&E 区域，
# 从而让分类器聚焦"高蛋白表达 + 对应形态"的联合模式
💡
为什么是"早期融合"而非晚期融合？Co-Attention 在特征层进行跨模态交互，允许模型学习哪些 H&E 形态区域与哪些蛋白通道最相关（可解释性来源），而晚期融合（分别预测再合并）会损失这种空间对应信息。MICA 相比单独 H&E 模型改善预后预测 C-index +21%，改善 ICI 响应 AUC +24~39%。
6
推断阶段：滑窗扫描与全切片重建
从单张 H&E WSI 生成完整 40 通道虚拟 CODEX 图
HEX Inference Pipeline（伪代码）
def hex_inference(wsi, model, stride=224):
# Step 1: 滑窗切分 WSI（40× 放大，224px 步长） tiles = sliding_window(wsi, size=224, stride=stride) # Step 2: 批量特征提取 + 蛋白预测 predictions = [] for batch in batched(tiles, bs=16): feat = model.backbone(batch) # MUSK 提特征 pred = model.reg_heads(feat) # 40 路回归输出 predictions.append(pred) # Step 3: 拼接重建完整虚拟 CODEX 图 virtual_codex = stitch_tiles(predictions, wsi.shape) # 输出: [H, W, 40] 的虚拟蛋白空间图谱 return virtual_codex # ~1.3 min/WSI on 8×L40S

  • 最低配置 单 GPU，≥8 GB VRAM 即可运行

🎯 损失函数：BCEDiceLoss
BCEDiceLoss（二值交叉熵 + Dice 联合）
L_total = λ₁ · BCE(p̂, p) + λ₂ · (1 - Dice(p̂, p))

BCE = -[p·log(p̂) + (1-p)·log(1-p̂)]
# 逐像素概率校准

Dice = 2·|p̂∩p| / (|p̂| + |p|)
# 区域重叠，对稀疏正样本鲁棒

# 联合：BCE 精细化边界，Dice 稳定稀疏区域

检测蛋白数5–10 种
